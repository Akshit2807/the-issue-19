# Asset credits

Every raster and audio file in `assets/` came from Wikimedia Commons. The licences are CC0, Public Domain, CC BY 2.0 or CC BY-SA 4.0.
Every file was resized and re-encoded to WebP (`cwebp`). Crops and other edits are noted in each row.
Under CC BY and CC BY-SA, a modified file must be credited and marked as changed. Keep this file, or put the same credits on a visible credits line on the site.
